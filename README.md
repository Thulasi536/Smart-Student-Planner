Smart Student Planner

A web application that helps students organize and manage their academic tasks efficiently.

Features

- User registration and login
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Set task priority and due date
- Store tasks separately for each user
- Save tasks in Firebase Firestore
- Responsive user interface

Technologies Used

- React.js
- Vite
- CSS
- Firebase Authentication
- Firebase Firestore
- Git and GitHub
- Vercel

Run Locally

1. Install Node.js.

2. Clone this repository.

3. Open the project folder in a terminal.

4. Install dependencies:
   
   "npm install"

5. Start the development server:
   
   "npm run dev"

6. Open the local URL displayed in the terminal.

Project Purpose

This project helps students manage their daily academic tasks in one place using a simple web interface.
